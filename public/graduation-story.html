解決する面倒・課題

出発点

頭の中の経験を、思い出すだけでなく再利用できる形にしたい。 仕事やプライベートで「どこか良い店を知らない？」「この人への手土産は何がいい？」と聞かれることが多かった。

よく相談されていた

会食・レストラン・手土産。判断基準は頭の中に蓄積していたが、その場で思い出すしかなかった。

その都度調べるのが大変だった

メモや記憶を毎回たどる。場面（接待、友人、犬連れ）に合う店を、条件で呼び出せなかった。

データ化したかった

自由メモだけではなく、検索できる項目として残す。暗黙知を、自分と相談相手が使える形にする。

ここがポイント

グルメアプリを作ることが目的ではない。個人の暗黙知を構造化し、検索・音声・将来はAIで再利用可能にすることがテーマ。

作りたいと思った理由

お題を選んだきっかけは、実用的で、自分の記録にもなるし、これからもアップデートできること。

実用的

相談されたその場で、条件から店や手土産を呼び出せる。

自分の記録にもなる

行った店、贈りたい手土産を、自分用の備忘録として残せる。

これからもアップデートできる

シートに足せば公開側も育つ。卒業制作で止めない前提。

工夫したポイントと苦戦したポイント

テクニカルなところは Cursor 上の指示と往復で進めた。宣伝ではなく、実際にやった実装・修正の記録。

工夫したポイント
  • シートを正本にする。アプリで直してもシートに残る
  • 公開は /、入力は /edit。来客に登録を出さない
  • Visit / Wishlist の2ステータス。M's Choice は将来の特集用
  • 条件・フリーワード・音声。IME変換中は検索を待たせる
  • トップはコピー主役。About M で選者の信用を置く
  • SEOは最低限。title / description / robots。編集は noindex。フッターは All Rights Reserved
苦戦したポイント
  • Apps Script：実行できない・無題のまま・送信がグレー
  • 写真：iPhone投入、ボード切り出しの黒フチ、円切り抜きの往復
  • 直すリストの写真が消えた → 公開と同じカードに戻した
  • IME：変換中に検索が走ると日本語が崩れる。公開でも直るまで往復
  • GitHub Pages と Simple Browser の接続拒否（-102）。開発サーバー未起動が原因

ここまでやってきたプロセス

1

指示書を置いて Grill Me

実装せず1問ずつ。PCブラウザ中心、一覧から始める、登録は後から、いきなりAIは作らない。写真は複数枚、犬連れ枠を追加。

2

データの置き場所

店・手土産の正本は Google シート。公開サイトはシートの CSV を読む。アプリからの保存は Apps Script でシートへ書き戻す。アプリで直してもシートに残る。最初の種データはリポジトリ内の JSON。シート接続後は、失敗しても種データへ黙って戻さない。サーバーは立てていない。

3

写真

店舗写真は撮影または店舗提供のURL。デザイン用イラストはサイト内の画像。iPhoneの写真を入れたい、ボード切り出しは黒フチで失敗、透過PNGをそのまま使う。テラス差し替え、円切り抜きの往復。

4

公開用と入力を分けた

来客は /、自分用は /edit。来客向けから新規登録と直すを外す。直すリストの写真が消えたので、公開と同じカードに戻した。行ったことがあるを上に。

5

分類項目

Restaurant：エリア、ジャンル、価格、フォーマル度、利用シーン、雰囲気、犬連れ。Gift：価格、相手・用途、日持ち・保存。ステータスは Visit / Wishlist の2つ。M's Choice は特集用で、ステータスではない。

6

検索機能

Restaurant / Gift に条件検索・フリーワード。条件はURLに残す。IMEは composition 中は待ってから検索。音声は Web Speech（日本語）。AI APIは使わず、既存検索に渡す。

7

デザイン

アイボリー、ネイビー、控えめなゴールド。女性向けすぎる表現を避け、男女とも使える上質で知的なトーン。About M の原稿と構成。チェックリストから「友人に喜んでもらえるか」「席のしつらえ」を外す。トップはロゴ＋コピー＋2カード。

8

Cursorで進めた公開と修正

GitHub Pages に出す。管理画面のスマホ対応。登録に入れないときは書き込み接続と /edit ルートを見る。公開ページは title・description・robots の最低限SEO。編集画面とこの図解は noindex。フッターに © All Rights Reserved。修正のたびにバグが出て、その都度直した。
