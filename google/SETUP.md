# Googleフォームからアプリへ反映する手順

毎日の入力はシートを触りません。iPhoneのフォームに書くだけです。

`createForms` は使わないでください。項目が二重になります。

## 手土産フォームを整える

1. スプレッドシートを開く
2. **拡張機能 → Apps Script**
3. 中身をすべて消して、このフォルダの `Code.gs` を貼り付けて保存
4. 上の関数名を **`resetGiftForm`** にして ▶ 実行する
5. スプレッドシートを再読み込みし、左下の **設定** タブを開く
6. 「入力URL」を開く。アドレスが `preview` で終わっていたら `viewform` に変える

## 写真を付けられるようにする

スクリプトでは写真欄を作れません。レストラン用・手土産用の両方で、編集画面から足します。

1. 設定タブの **編集URL** を開く
2. 右下の **＋** で質問を追加する
3. 種類を **ファイルのアップロード** にする
4. タイトルを **写真** にする（この名前のまま）
5. 必須にしない。最大ファイル数は 5
6. 「このフォームでファイルを収集しますか」と出たら **続行**
7. すでに「写真」という文章の質問がある場合は、それを消してから上と同じものを足す

## 写真の自動変換（初回だけ）

1. Apps Script で関数名を **`setupOnce`** にして ▶ 実行する
2. 権限を求められたら許可する（Drive の権限が出ます）
3. 設定タブの「写真の自動変換」が「準備できました」になっていれば成功です

写真付きで送ると、シートの `写真表示URL` にアプリ用リンクが入ります。リンクを知っている人が見られる設定になります。

## iPhone から入れるとき

1. 設定タブの入力URLを開く（Googleにログインした状態）
2. 必須だけ埋める（レストランは店名とステータス、手土産は商品名）
3. 写真は **ファイルを追加 → 写真を撮る**
4. 送信する
5. アプリを再読み込みする

## アプリから直す（自分のパソコンだけ）

公開サイト（GitHub Pages）には「直す」は出しません。直す画面は、このパソコンで起動したときだけ使えます。

1. プロジェクトフォルダで `npm run edit`
2. http://localhost:5173/ を開く
3. 詳細の **直す** から文章と写真を直す

合言葉の初回設定:

1. 最新の `Code.gs` を Apps Script に貼って保存する
2. 関数名を **`setEditTokenFromEditor`** にする
3. コード内の `var token = "";` の `""` の中に合言葉を書く
4. ▶ 実行する
5. 終わったら `""` に戻して保存する（コードに残さない）

スプレッドシートのメニューから設定する場合は、シートを再読み込みして **Omotenashi → アプリ編集の合言葉を設定** です。Apps Script の実行ボタンでは、そのメニュー用の関数は動きません。

ウェブアプリ（書き戻し用）の初回:

6. Apps Script で **デプロイ → 新しいデプロイ**
7. 種類は **ウェブアプリ**
8. 次のユーザーとして実行: **自分**
9. アクセスできるユーザー: **全員**
10. 出た `/exec` のURLを `.env.local` の `VITE_EDIT_SCRIPT_URL` に書く
11. `npm run edit` を一度止めて、もう一度起動する


## 最初の6件と手土産2件をシートへ移す

Apps Script で関数名を **`importSeedData`** にして ▶ 実行する。すでにシートにある店名は追加しません。
