# Googleフォームからアプリへ反映する手順

**毎日の入力はシートを触りません。** iPhoneのフォームに書くだけです。質問も、手で一つずつ作る必要はありません。

## 今あるシートでやること

1. スプレッドシートを開く
2. **拡張機能 → Apps Script**
3. 中身をすべて消して、`google/Code.gs` を貼り付けて保存（フロッピーアイコン）
4. スプレッドシートを再読み込みする
5. 上のメニュー **Omotenashi → 1. フォームを作成** を実行し、権限を許可する
6. 出てきた2つのURLが、レストラン用と手土産用の入力フォームです
7. 続けて **Omotenashi → 2. 準備（初回）** を実行する

写真付きで送ると、シートの `写真表示URL` にアプリ用リンクが入ります。

## アプリにつなぐ

1. スプレッドシート右上 **共有** → 「リンクを知っている人」が閲覧可
2. レストランのタブ、手土産のタブをそれぞれ開く
3. アドレスバーの `#gid=` のあとの数字がタブの番号です
4. そのURLをチャットに貼る

## iPhone から入れるとき

1. フォームのURLを開く（Googleにログインした状態）
2. 写真の質問で **ファイルを追加 → 写真を撮る**
3. 送信する
4. アプリを再読み込みする
